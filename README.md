## Overview

ChronoCraft Adobe Express Add-On provides a way to place ChronoCraft output into Adobe Express infographic documents instead of recreating that material manually. It is intended for workflows in which prepared, structured content needs to become a visual asset within Adobe Express.

The add-on uses a Node.js project structure and serves as a repeatable connection between content creation and design editing. Its workflow centers on transferring content into design documents while keeping the work within the Adobe Express environment.

## Workflow

A standard session can follow these steps:

1. Prepare the content produced by ChronoCraft.
2. Open the Adobe Express infographic document that should receive the content.
3. Load or run the add-on in Adobe Express.
4. Move the prepared content into the design document.
5. Check the resulting layout, spacing, and document organization in Adobe Express.

In short:

- ChronoCraft supplies the source content.
- Adobe Express is the destination design workspace.
- The add-on handles the transfer into an infographic-focused document.
